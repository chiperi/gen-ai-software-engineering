# Звіт з тестування хуків

Запуск: `.claude/hooks/test-hooks.sh` (кейси — у `.claude/hooks/test-cases.txt`).
Результат: **16 passed / 11 failed**.

Середовище: `jq` є; `prettier` і `ruff` **не встановлені**.

---

## Підсумок

| Хук | Працює | Проблеми |
| --- | --- | --- |
| `guard-bash.sh` (PreToolUse) | так, блокування спрацьовує (exit 2 доходить до моделі) | 7 обходів + 2 хибні блокування |
| `format.sh` (PostToolUse) | запускається, але нічого не форматує | рапортує успіх, якого не було |

## BUG-1 (critical) — `format.sh` брехливо рапортує успіх

`npx --no-install prettier` і `ruff` тут падають (не встановлені), помилка ковтається
через `|| true`, але хук усе одно друкує `✨🧹 Prettier gave X a spa day — squeaky clean!`.

Перевірено: після хука файл **байт-у-байт незмінний**.

```
FAIL  markdown really changed   hook reported success but file is byte-identical
```

Наслідок: і людина, і агент отримують хибний сигнал, що код відформатовано.
Фікс: перевіряти код виходу форматера і друкувати різні повідомлення для
«відформатовано» / «форматер не знайдено» / «форматер впав».

## BUG-2 (high) — `guard-bash.sh` обходиться тривіальними варіаціями

Збіг іде по сирому підрядку, без нормалізації, тому пропускає:

| Команда | Очікувано | Факт |
| --- | --- | --- |
| `rm -fr /` (інший порядок прапорців) | DENY | ALLOW |
| `rm  -rf /` (два пробіли) | DENY | ALLOW |
| `rm -rf ~` (снесе home) | DENY | ALLOW |
| `git push -f` | DENY | ALLOW |
| `git clean -fdx` (нищить untracked, як і `reset --hard`) | DENY | ALLOW |
| `curl … \|sh` (без пробілу) | DENY | ALLOW |
| `curl … \| bash` | DENY | ALLOW |
| `wget … \| sh` | DENY | ALLOW |

## BUG-3 (medium) — хибні блокування безпечних команд

| Команда | Очікувано | Факт |
| --- | --- | --- |
| `git push --force-with-lease` | ALLOW | DENY |
| `cat .env.example` | ALLOW | DENY |

`--force-with-lease` містить підрядок `--force`, тож хук блокує саме те,
що сам рекомендує у тексті помилки — суперечність.
Патерн `*".env"*` ловить `.env.example`, `.envrc` тощо.

## BUG-4 (medium) — гард ламає власну діагностику

Будь-яка команда, у тексті якої **згадується** заборонений патерн, блокується —
навіть якщо це не виконання, а тест або grep. Реально спостережено: тестовий
скрипт із літералом `rm -rf /` не запустився. Тому кейси винесені в окремий
файл даних. Ескейп-хатча (`ALLOW_UNSAFE=1`) немає.

## BUG-5 (low) — покриття matcher-ів

`PreToolUse` навішено лише на `Bash`. Прочитати `.env` через інструмент `Read`
або переписати файл через `Write` гард не завадить. Тобто це захист від
випадкового пострілу в ногу, а не security-межа — це варто зафіксувати в доці.

## BUG-6 (low) — `.md` у списку prettier б'є по швидкості

Кожен запис у markdown запускає `npx`, який на машині без prettier ходить
у реєстр npm (`npm error npx canceled … prettier@3.9.6`). Це затримка на
кожному редагуванні доків.

## BUG-7 (low) — немає обмеження шляху й таймауту

`format.sh` форматує будь-який `file_path`, включно з файлами поза проєктом
(перевірено на `/tmp`). У `settings.json` для хуків не заданий `timeout`.
